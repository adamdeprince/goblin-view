# Goblin Reactor Homebrew tap

Goblin Mosh and Odin Seat for macOS, maintained by Adam DePrince.

```sh
brew tap goblinreactor/tap https://brew.goblinreactor.com/homebrew-tap.git
brew install goblinreactor/tap/odin-seat
brew install goblinreactor/tap/goblin-mosh
```

Instructions, supported bottles, source and checksums:
https://brew.goblinreactor.com/

odin-seat is a terminal multiplexer with overlapping windows and an
Alt-tap menu (Apache License 2.0). goblin-mosh installs goblin-prefixed
commands without replacing stock Mosh (GPL-3.0-or-later with existing
notices and exceptions; source branch
https://github.com/adamdeprince/mosh/tree/low-bandwidth-mosh). Use the
source build when no tested bottle is available for your Mac.
Linux packages: https://apt.goblinreactor.com/
